# 3X-UI-Configs

Конфигурации на любой вкус и цвет для обхода блокировок в России. Сделаны для 3X-UI, но можно адаптировать.

## Настройка CDN (CDN Video)

URL ЛК: https://dashboard.cdnvideo.ru/

Создание ресурса:

1. CDN -> Добавить ресурс -> Большие файлы
2. В поле "Адрес" пишем свой YOURDOMAIN.SERVER.INHERE (Домен, ведущий на ваш сервер. Используется ТОЛЬКО С СЕРВЕРНОЙ СТОРОНЫ И CDN), порт - тот, что использует клиент для подключения. Не советую ставить никакой кроме 443.

Вы создали CDN-ресурс. Теперь настроем его:

1. Экспертные настройки -> Добавляем и включаем "Использовать HTTP2", "Использовать HTTP3", "Использовать только HTTPS", "Поддержка SSL-протоколов" (В поле "Выберите протоколы которые хотите использовать" выберете "SSLv3", "TLSv1.3", "TLSv1.2", "TLSv1.1"), "Разрешенные HTTP методы" (В поле "Разрешенные HTTP методы" выбираем все возможные методы. Технически же нам требуются только "POST" и "PUT") -> Применить
2. Конфигурация ресурса (Редактировать) -> Использовать HTTPS при запросе к источникам (Включить, Указать имя SNI-хоста) -> Передавать исходный Host-заголовок (Включить) -> Кеширование (Выключить) -> Желаемый CNAME (YOURDOMAIN.CLIENT.INHERE)* -> Раздача по HTTPS через CNAME (Включить) -> Добавить другой -> Выпустить сертификат -> Выпустить -> Применить

```plaintext
* - предварительно необходимо добавить соответствующую CNAME-запись, смотрите инструкцию от CDN-провайдера.
```

Готово. Вы всё настроили и теперь вы не долбоёб!

Из интересного, вам стоит сразу взять и купить какой-либо тариф, согласно вашему бюджету. Оплачивается он единоразово и на всегда. Трафик считается с 1 по 1 число. В целом, очень дёшево.

## Оговорки и советы

YandexCDN не советую брать из за космического количества метрик, которые на раз-два выдадут ваш VPN, но пока не ясно почему они так редко банят, возможно они ресейлят кластеры метрик РКН на обучение ТСПУ. VK CDN та же херня но в отличие от Яндекса вам сразу прилетит абуз и за ним бан (но оговорюсь, что метрики тут гораздо слабее). Beget хуйня от природы, Билайн CDN та же песня что и Beget, хотя CDNVideo и их (Билайна) дочерня, но всё же CDNVideo лучше.

Вся инфа и конфиги проверены на моём горьком годовом опыте а также опыте моего инсайдера из Yandex Cloude, по совместительству влдельце сети VPN-проектов. Я так же имею пока только 1 но достаточно популярный VPN-проект.
